Excel 格式说明

第 1 行为标题行，数据从第 2 行起。

列含义规则
A应用名称分组键；不能为空；支持合并单元格
D域名 FQDN每行一个；符合 DNS 规范
E原始 IP动态：换行分隔多个；静态：单个 IP
F目标 IP同 E 列规则
G类型必须为 动态 或 静态

动态：集合差分。address = E 有 F 无；new_address = F 有 E 无；交集 IP 两边均不写入。

静态：address = [E IP]，new_address = [F IP]（允许一侧为空）；回切互换两列。

输出文件命名：{应用名}_动态_切换.json、{应用名}_动态_回切.json、{应用名}_静态_切换.json、{应用名}_静态_回切.json

JSON 结构：[{ "fqdn": "...", "address": [...], "new_address": [...] }]

动态应急命令：上传 GSLB 全量 JSON，按域名和 IP 查询 dc_name、gmember_name。address 生成 status disable，new_address 生成 status enable。

静态应急命令：上传含 auth-zones.csv 的 DNS ZIP，按域名最长后缀匹配最细权威区，生成 .dns、modify rrs view ... rdata ... new_rdata ...、quit 命令。

匹配异常：找不到动态成员、静态权威区或静态任一侧 IP 为空时跳过并警告。
